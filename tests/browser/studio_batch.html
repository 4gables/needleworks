Builds Design-tab files with the site's own code: every starter on both hoops, every frame shape × border (appliqué included), arched lettering, monograms in every font, turned pieces, and an opened design combined with lettering. Each is checked with validatePES and POSTed to /save/<name>. Serve with tests/batch_server.py OUT, then run tests/pe900_check.py OUT/st_*.pes.
