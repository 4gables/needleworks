Class guarded: a file the app hands out that fails a machine or quality rule (category audit class 7). Seeded random but valid parameters over every engine, built with the site's own code the way the app builds them: lettering (every font, 5-120 mm, every fabric and thread weight, straight/arched/wave/bridge, 1-3 lines, automatic/satin/thin line, spacing, letter pairs, motifs either side), monograms, frames (every shape × border × size × hoop, patch patterns and blends, quilting, hanging loops), motifs × styles × sizes, appliqué letters, layouts of several pieces, turned hoops, starters, the bookmark, the design doctor's resize (50-250 %) of the sample files, saved designs with hostile fields (cleaned as Open saved does) and, reported apart (the picture engine is another stream's), pictures. Every file must pass validatePES and the app's own verdict (js/quality.js, which is tests/pe900_check.py's rules); each is POSTed to /save/fz_*.pes with the cases in fz_log.json, so run tests/pe900_check.py OUT/fz_*.pes after it. Too big for the hoop (said by the app, no Download) and nothing to stitch are counted, not problems.
